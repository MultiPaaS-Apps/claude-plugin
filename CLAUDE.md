# MultiPaaS for Claude Code

## Client surfaces

A change to something a builder sees (a skill, what a skill does or asks, or the CLI commands it runs) updates the
public docs on multipaas.com in the same story. The docs change is its own PR in
[MultiPaaS-Apps/website](https://github.com/MultiPaaS-Apps/website), linked from this repo's PR. A change with nothing
user-visible needs no docs change.
